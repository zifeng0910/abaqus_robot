# Project-local experimental contact target search

Search scope: tracked and local project Markdown, text, CSV, JSON, Python and Abaqus input files. Search concepts: restitution/rebound, high-speed collision, contact compliance/stiffness, Young's modulus, and their Chinese equivalents.

Result: **no credible user experimental restitution coefficient, incoming/outgoing collision speed, or robot/wall contact-compliance dataset was found**. Existing matches describe simulation collisions or the already-closed Reduced-Hydro audit; they are not experimental targets.

Consequence: the ζ=0.20 case is labelled `PROVISIONAL_CONTACT_DISSIPATION_PROBE`. It is a numerical anti-rebound design probe, not an experiment-calibrated material/contact model.
