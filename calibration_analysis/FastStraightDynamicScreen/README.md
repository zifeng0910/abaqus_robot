# Fast Straight Dynamic Screen

Four new short Explicit dynamics cases for visual selection of straight forward motion:

- `FAST_PLANAR_15HZ_A12_FORWARD`
- `FAST_PLANAR_20HZ_A12_FORWARD`
- `FAST_PLANAR_20HZ_A14P343_FORWARD`
- `FAST_ELLIPTIC_20HZ_A14P343_X2P5_FORWARD`

All cases use the frozen non-CEL rigid robot/tube, one-wall General Contact,
ReducedHydro, `G=6 mT`, `L=45 mm`, `B0=10 mT`, and `dt=1e-7 s`.

The main deliverable is `FastStraightScreen_4Way.gif` plus the four individual
GIFs and `Fast_Straight_Dynamic_Screen.md`. `forward_definition_audit.json`
records the canonical `+s` force-sign gate. The raw ODB files and extracted
dense private histories are intentionally local and ignored because they exceed
normal GitHub repository limits; the input decks, telemetry, identities, and
screening outputs remain tracked.
